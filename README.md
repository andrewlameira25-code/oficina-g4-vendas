# Oficina G4 — Página de Conversão de Vendas

Landing page oficial da **Academia Oficina G4** (Musculação, Cardio, Emagrecimento e Consultoria Online 360° — Coqueiro, Belém/PA).

## Executar localmente
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
```

Documentação técnica completa em `docs/arquitetura_landing_vendas.md`.
